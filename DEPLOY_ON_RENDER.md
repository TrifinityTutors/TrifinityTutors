# 🚀 Deploying Trifinity Tutors on Render

This project is fully configured for deployment on [Render](https://render.com). You have two easy deployment methods:

1. **Method 1: 1-Click Blueprint (Recommended)** — Automatically deploys both Frontend and Backend using the included `render.yaml`.
2. **Method 2: Manual Dashboard Setup** — Step-by-step setup via the Render Web UI.

---

## ⚡ Method 1: Blueprint Deployment (Fastest & Recommended)

Render Blueprints use the [`render.yaml`](./render.yaml) file to automatically spin up both the **Backend Web Service** and **Frontend Static Site** together.

### Step 1: Push your code to GitHub
Make sure all your latest commits are pushed to your GitHub repository:
```bash
git add .
git commit -m "feat: configure render deployment and blueprints"
git push origin main
```

### Step 2: Create a Blueprint on Render
1. Log in to [dashboard.render.com](https://dashboard.render.com).
2. Click the **"New +"** button in the top right and select **"Blueprint"**.
3. Connect your GitHub account and select your **`TrifinityTutors`** repository.
4. Render will detect `render.yaml` and show:
   - `trifinitytutors-backend` (Node Web Service)
   - `trifinitytutors-frontend` (Static Site)
5. Fill in the required environment variables prompted by the Blueprint UI:
   - `MONGO_URI`: Your MongoDB Atlas connection string.
   - `GOOGLE_CLIENT_ID`: Your Google OAuth Client ID.
   - `RAZORPAY_KEY_ID`: Your Razorpay Key ID (test or live).
   - `RAZORPAY_KEY_SECRET`: Your Razorpay Key Secret.
   *(Note: `JWT_SECRET` is automatically generated by Render securely).*
6. Click **"Apply"**. Render will build and deploy both services!

## 🛠️ Method 2: Manual Deployment via Render Dashboard

If you prefer to configure each service manually in the Render dashboard:

### Service A: Backend (Node.js Web Service)
1. In Render Dashboard, click **"New +" -> "Web Service"**.
2. Select your repository.
3. Configure the settings:
   - **Name**: `trifinitytutors-backend`
   - **Region**: Choose the closest region (e.g., Singapore or Frankfurt).
   - **Branch**: `main`
   - **Root Directory**: `backend`
   - **Runtime**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `node server.js`
   - **Plan**: Free
4. Under **Health Check Path**, enter:
   - `/health`
5. Under **Environment Variables**, add:
   | Key | Value | Description |
   |---|---|---|
   | `PORT` | `5001` | Server listening port |
   | `MONGO_URI` | `mongodb+srv://...` | MongoDB connection string |
   | `JWT_SECRET` | *(Random 32+ char string)* | Secret for signing JWTs |
   | `GOOGLE_CLIENT_ID` | `...apps.googleusercontent.com` | Google OAuth Client ID |
   | `RAZORPAY_KEY_ID` | `rzp_test_...` | Razorpay Key ID |
   | `RAZORPAY_KEY_SECRET` | `...` | Razorpay Key Secret |
6. Click **"Create Web Service"**.
7. Note down your backend URL (e.g., `https://trifinitytutors-backend.onrender.com`).

---

### Service B: Frontend (Static Site)
1. In Render Dashboard, click **"New +" -> "Static Site"**.
2. Select your repository.
3. Configure the settings:
   - **Name**: `trifinitytutors-frontend`
   - **Branch**: `main`
   - **Root Directory**: `frontend`
   - **Build Command**: `npm install && npm run build`
   - **Publish Directory**: `dist` (or `frontend/dist` if Root Directory is left blank)
4. Under **Redirects/Rewrites**, click **"Add Rule"**:
   - **Type**: `Rewrite`
   - **Source**: `/*`
   - **Destination**: `/index.html`
   *(This ensures client-side routes like `/tutors`, `/dashboard`, and `/admin` don't 404 on refresh).*
5. Under **Environment Variables**, add:
   | Key | Value | Description |
   |---|---|---|
   | `VITE_API_BASE_URL` | `https://trifinitytutors-backend.onrender.com` | Your backend URL from Service A |
   | `VITE_GOOGLE_CLIENT_ID` | `...apps.googleusercontent.com` | Google OAuth Client ID |
   | `VITE_RAZORPAY_KEY_ID` | `rzp_test_...` | Razorpay Key ID |
6. Click **"Create Static Site"**.

## 🔒 Crucial Post-Deployment Configurations

### 1. MongoDB Atlas Network Access
Render free instances do not have a static IP address.
1. Go to [MongoDB Atlas](https://cloud.mongodb.com/).
2. Under **Security**, click **Network Access**.
3. Ensure **`0.0.0.0/0` (Allow access from anywhere)** is added to your IP Access List so Render can connect to your database.

### 2. Google OAuth Console
Once your frontend domain is live (e.g. `https://trifinitytutors-frontend.onrender.com`):
1. Go to the [Google Cloud Console Credentials](https://console.cloud.google.com/apis/credentials).
2. Edit your OAuth 2.0 Client ID.
3. Under **Authorized JavaScript Origins**, add:
   - `https://trifinitytutors-frontend.onrender.com`
   - *(and any custom domain you connect)*
4. Under **Authorized Redirect URIs**, add:
   - `https://trifinitytutors-frontend.onrender.com`
5. Save changes.

### 3. Razorpay Webhook (Optional)
If using Razorpay webhooks for automated payment capture:
1. Go to the [Razorpay Dashboard](https://dashboard.razorpay.com/) -> **Settings** -> **Webhooks**.
2. Set Webhook URL to: `https://trifinitytutors-backend.onrender.com/api/bookings/webhook`.

## 💡 Notes on Render Free Tier
- **Spin Down / Cold Starts**: Free backend web services spin down after 15 minutes of inactivity. The first request after sleep may take ~50 seconds while the server boots up. The frontend static site runs on Render's global CDN and never goes to sleep.
- **Health Checks**: The backend exposes `/health` which returns `{ "status": "ok", "dbStatus": "connected" }`.
